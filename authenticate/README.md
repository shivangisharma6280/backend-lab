# JWT Authentication API

A mini backend learning task built using **Node.js, Express.js, and JWT** to understand user registration and token-based authentication.

## Features
- User registration API
- JWT token generation
- Handling missing tokens
- Handling invalid tokens
- Basic authentication and error handling

## Tech Stack
- Node.js
- Express.js
- JavaScript
- JSON Web Token (`jsonwebtoken`)

## Learning Outcomes
- Understanding JWT authentication
- Working with API requests and headers
- Implementing token verification
- Handling unauthorized requests
